# CardBridge 0.7.11 — Release Notes

**CardBridge** converts Koikatsu and Koikatsu Sunshine character cards into rigged PMX models — offline, with no game running, no plugins and no BepInEx. It also opens and edits native PMX models. This release is the current build of CardBridge and the first published installer release for this line.

**Download (recommended):** [`CardBridge-Setup-0.7.11.exe`](https://github.com/mobs3288/CardBridge/releases/download/v0.7.11/CardBridge-Setup-0.7.11.exe) — Windows 10/11, 64-bit. It installs to `Program Files\CardBridge` by default (a per-user install is also offered), creates the Start Menu shortcuts and Add/Remove Programs entry, and has a clean uninstaller that never touches your settings, library or exports.

**Alternative:** [`CardBridge-Portable-0.7.11.zip`](https://github.com/mobs3288/CardBridge/releases/download/v0.7.11/CardBridge-Portable-0.7.11.zip) — the same binaries, no installer. `.sha256` files are attached to the release for integrity checks.

## Install / first run

1. Download the installer above. Windows may warn about an unrecognised publisher — click **More info** → **Run anyway** (verify against the `.sha256` if you like).
2. Choose the install directory, pick the optional desktop shortcut, finish, then launch from the Start Menu.
3. On first run, point CardBridge at your Koikatsu (or Koikatsu Sunshine) folder and mods folder. The base-game data it needs is copied once into `%LOCALAPPDATA%\CardBridge\library`; the game is never needed at run time after that.
4. Drop a card (`.png`) onto the window, or open a `.pmx`, then press **E** to export.

## What's new since 0.3.0

- **Koikatsu Sunshine (KKS) support** and per-game KK/KKS library + mods profiles, selected automatically from the card marker with a mismatch warning and manual switching in Setup (0.4.0 / 0.4.1)
- **Native PMX import, lossless round-trip and editing in the viewer**: open `.pmx` files directly; Bones/Morphs/Material Workbench/viewport work on them; `cardbridge pmx info` and `cardbridge pmx roundtrip` (0.5.0 / 0.7.0)
- **Correct Unicode filenames** in exported PMX files (Korean, Japanese, Chinese, spaces and punctuation are preserved) (0.7.9)
- **Export fidelity fixes**: alpha-test cutout garments no longer paint a black band over the body; transparent-queue materials such as fishnet stockings stay translucent in MMD instead of turning flat black (0.7.10 / 0.7.11)
- Many further fixes to conversion, rendering, KK/KKS handling and the UI across 0.4–0.7 — see [`CHANGELOG.md`](../../CHANGELOG.md) for the full list
- Carries forward everything from the installer release: the branded Windows installer, the equivalent portable ZIP, and reproducible packaging

## Known limitations

- Works 100% for base-game items; modded cards often work but no guarantee is made for any specific mod. Mods shipped as `.rar`/`.7z` must be unpacked first.
- Some MaterialEditor colour/shader overrides are not applied; the face shape sliders are not applied yet.
- The PMX export approximates the game's shaders — use the "as exported" view (`X`) to judge it.
- Development continues; if something breaks, please [open an issue](https://github.com/mobs3288/CardBridge/issues).
