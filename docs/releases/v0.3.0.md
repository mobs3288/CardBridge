# CardBridge 0.3.0 — Release Notes

**CardBridge** converts Koikatsu character cards into rigged PMX models — offline, without the game running, without plugins or BepInEx. 0.3.0 is the installer release: CardBridge is now a proper Windows application you install and keep, instead of a loose exe you drop somewhere.

**Download (recommended):** [`CardBridge-Setup-0.3.0.exe`](https://github.com/mobs3288/CardBridge/releases/download/v0.3.0/CardBridge-Setup-0.3.0.exe) — Windows 10/11, 64-bit. Install into `Program Files\CardBridge` (or wherever you like), get Start Menu shortcuts, a working uninstaller and Add/Remove Programs integration, and keep all your data when you uninstall.

**Alternative:** [`CardBridge-Portable-0.3.0.zip`](https://github.com/mobs3288/CardBridge/releases/download/v0.3.0/CardBridge-Portable-0.3.0.zip) — the same build without the installer: unzip and run. Both distributions are built from the same binaries and have identical features. `.sha256` files are attached to the release for integrity checks.

## Installing

1. Download `CardBridge-Setup-0.3.0.exe` (above).
2. Windows may show "Windows protected your PC" — the installer is not code-signed. Click **More info** → **Run anyway**, and verify against the `.sha256` if you want.
3. Pick a folder (default `Program Files\CardBridge`), optionally create a desktop shortcut, finish.
4. Launch from the Start Menu. The first run asks for your Koikatsu folder (the one that contains `abdata`) and copies the data it needs into `%LOCALAPPDATA%\CardBridge\library` — about 0.9 GB, once — then asks for your mods folder (or skip it).
5. Drop a card `.png` on the window, press **E**. That is it.

Uninstalling removes CardBridge and its shortcuts. **It never deletes** your settings, asset library or exports — those live in `%LOCALAPPDATA%\CardBridge` and wherever you exported to.

## What changed since 0.2.1-alpha

### Installer and distributions
- A branded Windows installer (Inno Setup 6): wizard artwork derived from the CardBridge logo, Program Files install, Start Menu + optional desktop shortcut, Add/Remove Programs, in-place upgrades, clean uninstaller.
- A portable ZIP with the same binaries.
- Reproducible release packaging (`installer/build_installer.ps1`): Release build, staging verification (files, version metadata, Windows-system-DLL-only dependencies), SHA-256 sums.
- Both executables carry the same version resources as the app (the CLI got the same treatment as the viewer).

### Features
- **Material Workbench** — live material overrides for modded items, texture inspector, diagnostic viewport modes.
- **Selective Import** — import from an outfit/Coordinate file one component at a time (Add / Replace / Keep / Skip), with three live views and nothing applied until you press Apply.
- **Coordinate import** — Koikatsu Coordinate PNGs and `【KoiKatuClothes】` outfit files apply to a loaded character (merge as clothing or replace as coordinate). The card on disk is never modified.
- **Clothing export** — write one outfit back out as a `【KoiKatuClothes】` file (`cardbridge clothes`, or the viewer's Export clothes button / `Shift+E`).
- **Mesh simplification + LODs** — `--simplify` / Optimize tab, and stacked `name_lod1..4.pmx` files with per-part budgets that never drop visible clothing.
- **Body measurements** — Bust / Waist / Hip measured in centimetres; type an exact value, the shape solves to it.
- **Proportion correction** — optional, non-destructive suggestion layer for cards with unusual sliders or ABMX scales; `--proportions`, `--normalize-*`, `--print-diagnostics`.
- **Skin shading and AO bake** — cleavage shading, underboob fold control, nipple colour, and Koikatsu's own cavity/ink look baked into the body skin (`--skin-ao`, default 0.85).
- **Translucency brush** — hand-paint see-through regions on garments; exports as proper transparent materials.
- **Bust soft-physics chains** in the PMX (default on) and a live physics preview in the viewer (`Y`).
- **UI redesign** — two-row tab grid, flat widget kit, modern pickers, single-accent charcoal theme.
- **Performance** — ~5× faster conversion, ~20 % lower peak memory, deterministic bakes.
- GPU skinning for the viewer, with WARP/software fallbacks.

### Notable fixes
- MikuMikuDance crashed a few seconds after opening a model with facial morphs (MMD keeps the file-wide listed-morph count in one byte). The `Exp` frame and the facial tabs now share the 255-slot listed-morph budget — priority morphs first, proportional split, nothing listed twice.
- Crash in the software shader bake (0xC0000005) when the translucency brush invalidated mip chains mid-bake.
- Crash when an ABMX bone had zero scale.
- Double-layered "studio-alpha" garments drew their lining on the outside; the lining is now detected and confined to the interior.
- Brows, the eyelash line and other face detail lines baked white instead of taking the card's colours.
- Garment items hidden by their own LODs no longer disappear; the simplifier never removes visible clothing.
- Deterministic texture baking (no order-dependent colours).

## Known limitations

- The base game works 100%. Many modded cards convert well; not all of them, and no guarantee is made for any specific mod. `.rar`/`.7z` mods must be unpacked first.
- MaterialEditor main-texture replacements work; colour/float/shader overrides do not yet.
- The face shape sliders are not applied yet (body sliders are).
- Exports approximate the game's shaders; press `X` ("as exported") in the viewer for exactly what MMD will see.
- **Experimental:** face morph effects (Eye Roll, Heart Eyes, Sweat) — implemented and unit-tested, not yet verified against a real character render.

## Development pace

Starting **1 December 2026**, development slows down, but CardBridge is still in active development. If something breaks, [open an issue](https://github.com/mobs3288/CardBridge/issues).

## Upgrading from 0.2.x

Run the installer over your existing folder. The app files are replaced, obsolete names are cleaned up, and your settings, library and exports in `%LOCALAPPDATA%\CardBridge` are untouched. If you used the loose `CardBridge-0.2.x-alpha.exe`, you can delete it after the installer run.
